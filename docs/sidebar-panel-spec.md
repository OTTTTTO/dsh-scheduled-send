# Doublecheck spec

## Goal
dsh-scheduled-send 新增侧边栏「定时任务」入口与独立面板页：展示全库所有会话的未发送定时任务（按 sendAt 升序、含会话标识），点击条目跳转到对应会话，条目提供跨会话取消按钮；新建仍在会话内 ⏰ 完成。

## Scope
宿主侧 state 路由支持全量模式（不按 conversationId 过滤，返回任务+会话标识）；客户端新增侧边栏入口与面板页组件（挂载点需调研 dsh-client-ui-sidebar/session 的槽位或导航注册机制，参照 dsh-usage-stats 的侧边栏入口实现）；跨会话取消复用既有 DELETE 路由；会话跳转用客户端会话切换 API（调研 useSession/导航入口）。不改调度/投递/持久化核心。

## Acceptance criteria
1) 侧边栏出现「定时任务」入口（含未发送任务数角标），点开独立面板页；2) 面板列出所有会话的未发送任务：升序、内容摘要、计划时间、倒计时、会话名/ID 标识；3) 点击条目跳转到对应会话（该会话 dock 可见该任务）；4) 条目上的取消按钮跨会话取消成功且列表即时移除；5) 空列表显示友好空态；6) 既有功能（⏰ 创建、dock、投递、补发）零回归，全量 npm test 0 失败，新增测试先红后绿。

## Failure modes
会话已删除/不可跳转：条目置灰标注「会话不存在」仍可取消；跳转 API 不可用：降级提示手动切换并保留取消；全量列表性能（任务极多）：分页或上限 100 条+提示；侧边栏挂载点不存在：按 usage-stats 同型入口实现，若机制不同则以实际为准并在 README 标注。

## Priorities
跳转可靠性 > 列表信息完备 > 角标/空态装饰；核心调度不动。

## Non-goals
不在侧边栏新建任务、不做已投递历史页、不做批量操作、不改宿主调度逻辑。
