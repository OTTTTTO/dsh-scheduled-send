# Doublecheck spec

## Goal
dsh-scheduled-send 五项修复：切换会话时任务列表即时刷新不消失；折叠策略改为仅常显最近 1 条（其余收进「N 条定时任务」）且任意条数可手动折叠全部；彻底移除模型切换功能（UI/存储/投递路径/路由，旧任务 model 字段忽略）；创建后必即时显示（修复竞态）；移动端自适应+触控优化（popover 小屏全宽、目标≥40px、不溢出、默认收起）。

## Scope
改 dsh-scheduled-send 的 src/* 与 lib/client.js 重建；移除 model-switch 相关宿主/客户端代码与测试（改断言），保留会话隔离、用户气泡投递、持久化补发、取消等核心；不改 glm-coding-plan-guard。

## Acceptance criteria
1) 切换会话瞬间列表更新为目标会话任务，无需刷新；2) >1 条时仅显示 sendAt 最近 1 条 + 「N 条定时任务 ⌄」，点开全量、再点收起（手动折叠全部任何时候可用）；3) 界面与数据面无任何模型切换入口/字段/路由，创建 popover 无模型下拉，旧任务含 model 字段仍正常投递不报错；4) POST 成功即入列（修复乐观更新竞态：失败回滚并保留表单）；5) 小屏（≤480px）popover 全宽弹出、按钮/输入触控目标≥40px 高、条目不横向溢出、折叠默认收起；6) 红绿 TDD，全量 npm test 0 失败。

## Failure modes
切换会话时 state 请求失败：显示上一次数据+错误提示不闪空；移除模型功能后旧 tasks.json 含 model：投递忽略该字段；乐观入列与响应竞态：以服务端返回条目替换本地条目（id 去重）；小屏过度换行：允许纵向增长但禁横向滚动。

## Priorities
可靠性（1/3/4 修复）> 折叠策略 > 移动端观感；核心投递路径不动。

## Non-goals
不做底部抽屉/滑动手势、不做模型切换回归计划（将来另议）、不做 PWA。
