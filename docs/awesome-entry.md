# awesome-dsh-plugin 收录条目（PR 文案）

## English

**Scheduled Send** (`@ottttto/dsh-scheduled-send`) — Schedule your draft and have it sent as you at the chosen time: unattended, per-conversation, with offline catch-up delivery after restart. A ⏰ button next to the composer turns the current draft into a scheduled task (list with countdown, one-click cancel); at due time the message is delivered to the original conversation as a normal user bubble and triggers the model response. No telemetry, data stays local.

```bash
dsh plugin --profile web add @ottttto/dsh-scheduled-send@0.2.0
```

Repo: https://github.com/OTTTTTO/dsh-scheduled-send · MIT

## 中文

**定时发送 Scheduled Send**（`@ottttto/dsh-scheduled-send`）—— 到点以你的身份发送：无人值守、会话隔离、断电补发。输入框旁的 ⏰ 按钮把当前草稿变成定时任务（折叠列表 + 倒计时 + 一键取消）；到点后消息以正常用户气泡出现在原会话并自动触发模型响应。无遥测，数据全部本地。

```bash
dsh plugin --profile web add @ottttto/dsh-scheduled-send@0.2.0
```
